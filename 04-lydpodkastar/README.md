# Lydpodkastar — Syntetiserte to-verts lydsamandrag (1972–2026)

- **Lydarkiv (`1,34 GB` / `1 373,41 MB`)**: **764** KI-genererte to-verts lydsamandrag i MP3-format (`podcast_<nou_id>.mp3`), pakka i [`nou_podcasts_mp3_1972_2026.tar`](https://github.com/tordieltor/nouinnsikt-open-data/releases/tag/v1.0.0-data) under **GitHub Releases**.
- **Episodekatalog**: [`podcast_catalog.csv`](podcast_catalog.csv) (koplar `nou_id`, tittel, år, departement, utvalsleiar og MP3-filnamn).
- **Manuskript / dialogtekst**: Ligg inne i `document_profile.podcast_script` i [`../01-tabellar-og-katalogar/relasjonstabellar/nous.jsonl.gz`](../01-tabellar-og-katalogar/relasjonstabellar/nous.jsonl.gz).
- **Atterhald**: Lydsamandraga er syntetiserte med språkmodellar (LLM) og tekst-til-tale (TTS) som lytte- og oversiktsverktøy, og må ikkje siterast som utvalet sin offisielle tekst.
