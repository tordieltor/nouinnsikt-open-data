# Lydpodkastar — Syntetiserte to-verts lydsamandrag (1972–2026)

- **Enkeltfiler rett i mappa ([`lydfiler/`](lydfiler/))**: Alle **764** KI-genererte to-verts lydsamandrag i MP3-format ligg tilgjengelege einskildvis sortert etter år (`lydfiler/1972/`–`lydfiler/2026/`, t.d. `lydfiler/2022/nou-2022-20_2951826.mp3`).
- **Samla pakke for nedlasting i eitt klikk (`1,34 GB`)**: [`nou_podcasts_mp3_1972_2026.tar`](https://github.com/tordieltor/nouinnsikt-open-data/releases/tag/v1.0.0-data) under **GitHub Releases**.
- **Episodekatalog**: [`podcast_catalog.csv`](podcast_catalog.csv) (koplar `nou_id`, tittel, år, departement, utvalsleiar, MP3-filnamn og direkte `github_path`).
- **Manuskript / dialogtekst**: Ligg inne i `document_profile.podcast_script` i [`../01-tabellar-og-katalogar/relasjonstabellar/nous.jsonl.gz`](../01-tabellar-og-katalogar/relasjonstabellar/nous.jsonl.gz).
- **Atterhald**: Lydsamandraga er syntetiserte med språkmodellar (LLM) og tekst-til-tale (TTS) som lytte- og oversiktsverktøy, og må ikkje siterast som utvalet sin offisielle tekst.
