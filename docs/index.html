NOUinnsikt er avrunda som aktiv nettjeneste — alle rådata er fritt tilgjengelege på GitHub

Den interaktive netttenesta på nouinnsikt.no (med direkte KI-søk, bakgrunnsdatabasar og dynamiske visingar) er stengd ned. For at kunnskapsarbeidet skal kome forskarar, studentar, journalistar, forvaltninga og utviklarar til gode i framtida, er heile det strukturerte datagrunnlaget frå 54 år med Noregs offentlege utgreiingar (1972–2026) frigitt som opne, maskinlesbare rådata utan innlogging eller kostnad.

For international researchers: Active cloud hosting for NOUinnsikt has concluded. Complete empirical datasets covering 54 years of Official Norwegian Reports (NOU 1972–2026)—including relational CSV/JSONL tables, committee rosters, citation networks, minority dissents, legislative tracking, cleaned Markdown fulltext, 768-dim vector embeddings, and MP3 audio summaries—are permanently archived in open formats on GitHub.

Spør rådata direkte med Python eller DuckDB

Du treng verken API-nøkkel eller databaseserver — les CSV og JSONL rett frå klona mappe eller URL:

-- DuckDB SQL direkte mot rå CSV-filer:
SELECT year, count(*) AS nou_count
FROM read_csv_auto('datasets/relational/nous_flat.csv')
GROUP BY year ORDER BY year DESC LIMIT 5;

SELECT name, count(*) AS chaired_count
FROM read_csv_auto('datasets/relational/nou_authors.csv')
WHERE role = 'leader'
GROUP BY name ORDER BY chaired_count DESC LIMIT 10;
